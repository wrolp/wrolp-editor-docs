WROLP Editor

A small local text editor for Windows

Tauri v2 + React + TypeScript, with Monaco Editor in the editing surface. Tabs, draft recovery, Markdown preview, PDF reading, built-in Git source control and AES-256-GCM encryption — all of it on your own machine.

Features

Edit, read, compare and commit without leaving the window.

Built-in Git source control

A fourth sidebar view drives the real repositories behind the group folder: staged and unstaged changes, per-file diffs, commits and history, branches, a three-way merge editor, and fetch / pull / push over HTTPS or SSH with progress and cancel.

Docs

AES-256-GCM encrypted files

A self-describing container with a password-derived key. Encrypt-on-save-as, new encrypted file, change password, remove encryption, an idle lock, optional remembering into Windows Credential Manager, and drafts encrypted under the same key.

Docs

Version history and side-by-side diff

When it is on, every save by hand records what the file said. Any two versions can be compared side by side, or either against what is open now; fold down to the changes, collapse untouched regions, or put a version back into the editor.

Docs

Markdown preview

Renders beside the source with GitHub-style syntax, an outline and Monaco-coloured code blocks; mermaid / plantuml / graphviz fences become SVG. HTML written by the document is rendered after a whitelist clean-up — scripts and event handlers never pass.

Docs

PDF reader

Drawn by pdf.js as one continuous scroll, from 25 to 400 %. White, cream, eye-care green, inverted night paper or a colour of your own; hierarchical bookmarks fold branch by branch, auto-scroll runs at a set speed, and the last page read is remembered per file.

Docs

Drafts, auto-save and line colouring

Drafts hit the disk about 500 ms after you stop typing, and flush at once on a tab switch, a tab close or window blur. Lines that differ from the disk copy are coloured: additions green, replaced text amber. Auto-save lands after a pause, not mid-sentence.

Also in the box

  • Tab groups: tabs, cursor positions and the directory tree switch together
  • Picture gallery: a whole folder in natural order, four ways to view it
  • Batch rename: pattern tokens or a regular expression, previewed line by line
  • Configuration backups: snapshots on open and close, restore any one of them
  • Single instance and Windows context-menu integration
  • English and 简体中文, following the system by default
  • Signed auto-update that prompts and never installs on its own
  • Window size, position and maximised state restored

Local first

No account, and every file read and write stays on the machine.

The picture gallery reads a local folder only — no image host, no upload, no generated links. Remote sync happens only when you run git fetch / pull / push yourself, and the credentials live in state/git.json, outside both settings and configuration backups.

How updating works

The app checks GitHub for a newer release after startup and every six hours, and only prompts — it never installs on its own. Download and install fetches the signed installer, hands it to the passive installer and restarts. The automatic check can be turned off in Settings → About.

Build from source

Needs the Rust MSVC toolchain, the Visual Studio C++ build tools workload, and Node.js ^20.19 or >=22.12.

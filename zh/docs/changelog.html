发行说明

v0.0.3、v0.0.2 与 v0.0.1 的新特性、修复与内部变更。

v0.0.3 — 2026-11-07#

第三个版本：PDF 有了自己的阅读器，标签菜单里多出文件设置的浮层，文件可以从 Windows 粘贴或拖进资源管理器。

新特性#

  • PDF 阅读器 —— PDF 在自己的标签里由阅读器绘制：按字节范围读取、按需绘制页面，视图自动滚屏，并记住页码，重新打开时接着上次的位置。状态栏把文件标为 PDF、显示页并可跳转，书签按层级树展开、可全部展开或折叠，阅读器的工具收在角落的标签后面。
  • Markdown 大纲 —— 目录列收进角落标签，可设为默认打开。
  • 标签条 —— 悬浮提示给出文件名和所在目录；过长的标签名按与文件树相同的省略设置截断；标签可全部关闭或关闭一侧；可从菜单把标签移到最左或最右；标签宽度随文字自适应。
  • 标签菜单：文件设置 —— 「文件设置」改为在行侧展开的浮层，不再整块替换菜单：预览、缩略图和十个单文件覆盖项（显示空格、自动换行、粘滞滚动、缩进宽度、插入空格、按文件内容检测缩进、显示缩略图、编码方式、换行符、版本记录）就地切换，每项带当前值与选项列表。对话框保留，用于查看检测到的编码，以及把全部覆盖项恢复为全局默认。
  • 资源管理器 —— 从 Windows 粘贴（Ctrl+V）或拖入的文件落到指针下的目录，拖动时该目录会高亮；拖到其它位置则把文件作为标签打开。「属性」用应用自己的对话框显示文件或目录的大小、时间与属性。
  • 源码管理 —— 面板内可克隆远程仓库；管理暂存与本地忽略的路径；面板变窄时头部动作收进菜单；折叠未变更区域并在分栏与统一视图间切换；编辑远程地址；从行菜单打开改动的文件；更改列表可按目录分组并记住选择；已在进行的 push 可以真正停止。
  • 设置 —— 「常规」页按卡片重新分组；状态栏可隐藏；语言与主题默认跟随系统。
  • 更新 —— 启动后以及每六小时检查一次新版本，更新程序读取全部已发布版本。

修复#

  • 悬浮提示完整显示路径、不再截断，并保证留在窗口内；源码面板的提示只给出所在目录，不再重复文件名。
  • 提示气泡避开指针，也避开它描述的那一行文字。
  • 快捷键不会越过对话框，文件树可以复制父目录路径。
  • 大目录与长历史的场景下，资源管理器与源码面板保持流畅。
  • 较宽的 mermaid 流程图布局正确。
  • 暂存数量过长时截断，不再换行。
  • 应用自己的菜单上不再弹出系统右键菜单。
  • 翻转页面时图片保持自身颜色。
  • 保存更可靠，git 凭据不再写进配置文件。

内部#

  • 版本号提升到 0.0.3
  • 发布构建开始前会清理 target/ 与 dist/

v0.0.2 — 2026-10-31#

第二个版本：源码管理到来，对比学会折叠与换行，Markdown 可以导出，编辑器与预览也各自有了右键菜单。

新特性#

  • 源码管理 —— 侧栏新增第四个视图，操作分组目录背后的真实 git 仓库：暂存与未暂存改动、diff、暂存 / 取消暂存 / 丢弃、提交与 amend、带提交图的历史、分支，以及 HTTPS / SSH 上的 fetch / pull / push，带进度、取消与主机指纹校验。合并冲突在三栏编辑器里逐块解决，一个目录下也可以有多个仓库。
  • 本机 Git 状态 —— 通过 .git/info/exclude 本地忽略未跟踪路径，或对已跟踪文件设置「假设未修改」；都能在「本地 Git 设置」里撤销。
  • 提交差异标签页 —— 右键一次提交，在一个只读标签里看它改动的全部文件：按文件折叠、可逐个展开，每个 diff 还能折叠到只显示改动行。
  • 对比 —— 默认复用同一个比对标签页，不再每次新开（可在设置里改回）；diff 头部新增「只看变更」与「自动换行」开关。折叠后保留真实行号。
  • 右键菜单 —— 编辑器与 Markdown 预览各有自己的右键菜单：编辑器为剪切 / 复制 / 粘贴 / 全选，预览为复制 / 复制代码 / 复制链接 / 全选，文案跟随界面语言。
  • Markdown 渲染 —— 文档自带的 HTML 经更严格的清洗后渲染（行内与块级标签、表格、媒体、details），内联 SVG 正常绘制，图片文件名正确解码。
  • 导出 —— Markdown 文档可经打印对话框导出 PDF，或导出 .docx；图片会内联（过大的重新编码），进度面板显示进度并可拖到一边，打印出的 PDF 以文档名命名。
  • 资源管理器 —— 支持批量重命名，每个标签分组各有自己的目录，名称按自然顺序排序，目录里的图片可在图库标签页里浏览；源码管理面板可把资源管理器切到某个仓库的目录，编辑器读不了的文件可用默认应用打开。
  • 其它 —— 透明图片可选择衬底颜色；最近文件可清空或批量移除；HEAD 或远程引用变化时历史会自动刷新。

修复#

  • 打印出的 PDF 以文档名命名，不再是应用名。
  • 鼠标悬停时提示会先等一会儿再关闭。
  • 提交的文件 diff 从选中的仓库读取，而不是它上面的目录。
  • 提交后历史会刷新（包括第一次提交之前日志为空的情况），fetch / pull / push 之后也会刷新。
  • 被拒绝的 SSH 主机密钥会被保留，面板才能就它发问。
  • 恢复配置后，随后的重载不再把恢复撤销。
  • 备份目录改为经后端打开；恢复确认出现在它所属的那一行下面。
  • 资源管理器刷新时保留已展开的目录；最近文件列表会跟随变化。
  • 滚轮可滚动「最近文件夹」菜单。
  • 更新检查读取全部已发布版本，并把预发布排在它所预告的正式版之下。
  • 保存 CRLF 文件时按真实改动着色，而不是按行尾差异。
  • 版本时间显示为 yyyy-MM-dd HH:mm:ss。
  • 窗口先定位再显示，最大化启动不再闪一下。
  • 只有发布脚本会签名更新产物。
  • 空分组不再接管正在离开的标签。
  • 资源路径在作用域检查前按大小写不敏感匹配。
  • Markdown 大纲与预览保持同步；大纲出现时预览不再换位。

内部#

  • 版本号提升到 0.0.2
  • git 提交包装函数保留在 cfg(test) 之后；合并测试调用由 rustfmt 折叠
  • 发布脚本以自身 tag 与「版本高于线上版本」作为发布门禁

v0.0.1 — 2026-10-21#

首个版本。

这是什么#

一个 Windows 上的小型本地文本编辑器，基于 Tauri v2 + React + TypeScript，编辑面使用 Monaco。

能做什么#

  • 标签与编辑 —— 一个窗口开多个文件；按扩展名高亮、小地图、每个标签独立的光标与脏标记、标签下拉列表与标签右键菜单
  • 保存 —— Ctrl+S；未命名过的标签走「另存为」。两项清理可选且默认关闭：去掉行尾空白，以及补上文件缺失的末尾换行
  • 未保存改动 —— 与磁盘内容不同的行会被染色：新增的文字绿色，被替换的已存文字琥珀色；保存后标记消失
  • 换行符 —— 按文件原样读入、按原样写回；可对单个文件强制指定，状态栏显示这次保存会写哪种
  • 草稿 —— 编辑时防抖保存，切换标签、关闭标签和窗口失焦时落盘，重开时恢复，可选「恢复 / 丢弃」对话框
  • 自动保存 —— 默认关闭；开启后在停顿处写入屏幕上的文件，而不是写到一半
  • 侧边栏 —— 资源管理器树（文件夹懒加载）、最近打开的文件、版本历史；可拖动，宽度持久化
  • 版本历史 —— 默认关闭；任意两个版本、或任一版本与当前内容都可并排比较，并可折叠到只显示差异
  • 加密文件 —— 自描述的 AES-256-GCM 容器，由密码派生密钥；空闲自动锁定，可选择把密码记住在 Windows 凭据管理器
  • 单实例 —— 第二次启动把文件路径交给已在运行的窗口
  • 语言 —— English 与简体中文，在设置里切换
  • 更新 —— 设置 → 关于按需检查 GitHub 发布，下载签名安装包后交给静默安装器

丢失加密文件的密码即丢失文件：没有恢复码，也没有主密码。

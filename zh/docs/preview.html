PDF 与图片

PDF 阅读器的纸张、书签与自动滚动，以及目录级图片画廊的四种视图。

阅读 PDF#

.pdf 标签由 pdf.js 绘制，不经过编辑器。整篇页面连成一列滚动，状态栏的页码框可以按页号跳转；离开时的位置会按文件记下（页码加页内位置），下次打开回到原处。

大小。 默认「适应」：页面按窗格宽度铺满，输入框里显示折算出的百分比；左右箭头按 50、75、100、150、200、300 % 递进，也可直接输入（25–400）。适应以页面自身宽度为准，所以尺寸特殊的扫描件同样铺满窗格。

纸张。 白纸、米黄、护眼绿、夜间，或系统取色器给的任意颜色。夜间反转纸张与文字，但把图片从反相里挖出来，页面上的照片还是原来那张。选择会被记住。

书签。 文档带大纲时，可从角落按钮展开成一列——左右侧在「设置 → 预览」里选，同一处也能让它随文档自动展开。有子项的分支点自己的 −/+ 方框逐支折叠，或从列头一键展开 / 收起全部；每层缩进处的虚线刻度让很深的目录也读得清。点标题跳到它指定的页；指向文档外的书签不会把读者带偏。

自动滚动。 工具栏按钮让页面动起来，慢一点 / 快一点调整速度（10–240 px/s）。滚轮或双击会停下；单击只收起工具条，所以点一下页面继续读不会丢失位置。

图片浏览#

在资源管理器里右键文件夹（或目录树下方的空白处），选「浏览图片」。目录会在自己的标签里打开，四种方式看的是同一条自然序列表：

  • 上下排列（默认）：一张接一张排开，宽度不超过原图、不放大，上方显示序号、文件名、尺寸与大小。
  • 一张张：单张大图，带缩放、适应窗口、100%，下方是同一目录的胶片条。
  • 轮播：同一个画面按间隔自动前进。鼠标停在画面上会暂停，窗口失焦也会停；间隔与是否循环在设置里，也可从画廊工具条直接改。
  • 整页网格：方形缩略图，可选大、小两档。点任意一张就按该位置进入「一张张」。

普通标签里打开的图片，工具条上有「浏览所在文件夹」，会打开该目录并停在当前这张。画廊只读本地目录——不接图床、不上传、不生成直链。

图片的透明像素背后默认垫一层跟随主题的棋盘格。工具条上的几个色块（设置 → 常规 里也有同样一排）可以把它换成白色、黑色，或者用系统取色器自选一个颜色——白色 logo 不再消失在浅色底上就是靠这个；画廊的缩略图一起跟着变，选完对所有图片都记住。

只有视口附近的图片会挂载，离开两屏的 <img> 会从 DOM 移除，让 Chromium 释放已解码的位图；上下排列会用已量到的高度占位，滚回来不会跳位。上下排列里 ↑/↓ 滚动列表、←/→ 换图；「一张张」与轮播里 ←/→ 换图。Home/End 跳首末，Space 播放/暂停轮播（在上下排列里翻一屏），Esc 回到「一张张」。资源管理器里改名、删除或粘贴后，开着的画廊会重新取列表。gallery:// 标签不会写进分组存档，重启只恢复文件标签。

既是图片又是文本的文件（最典型的是 SVG）两种看法都行。切到只显示文本时会出现提示：「显示图片」直接切回图片，右侧的 × 让这个文件不再提示。

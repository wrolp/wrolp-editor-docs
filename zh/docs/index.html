概览

WROLP Editor 是什么，以及各模块的行为一览。

下面的内容来自项目 README 与发行说明，随版本同步。

编辑器与窗口

快捷键、标签分组、窗口状态还原与界面语言。

 PDF 与图片

PDF 阅读器的纸张、书签与自动滚动，以及目录级图片画廊的四种视图。

 文件操作

批量重命名、配置备份快照与只读并排对比。

 版本记录

按文件保存的私有历史：记录、比对、取回，以及与 git 的区别。

 源码管理

暂存、提交、分支、三栏合并，以及 HTTPS / SSH 上的 fetch、pull、push。

 加密文件

AES-256-GCM 容器格式、三个入口、解锁与空闲锁、记住口令与草稿。

 数据存放位置

配置目录下的各个文件，以及前端可调用的 Tauri 命令。

 开发指南

环境要求、本地开发、打安装包、发布闸门与脚本。

 发行说明

v0.0.3、v0.0.2 与 v0.0.1 的新特性、修复与内部变更。

 许可证

WROLP Editor 以 MIT 许可证发布。

一款 Windows 本地文本编辑器。

技术栈：Tauri v2 + React + TypeScript，编辑区用 Monaco Editor。

功能一览#

模块 行为
多标签 单窗口多文件；标签脏标记、已打开文件下拉列表、标签右键菜单（可关闭所有 / 关闭左侧 / 关闭右侧）
编辑 Monaco：按扩展名高亮、minimap、每个文件独立 model、切回标签还原光标
保存 Ctrl+S 写回文件并清除该草稿；未落盘过的 Untitled-N 走另存为。另有两项默认关闭的整理：去除行尾空格、补上缺失的行末换行——都先写回缓冲区，所以屏幕上看到的就是写进文件的字节
未保存的修改 与磁盘上那份不一致的行会被染色：新增的行偏绿，改掉了原有文字的行偏黄，保存后标记消失。比对在 src/lib/dirtyDiff.ts：工作台自带这套，独立版 Monaco 没有
换行符 读到什么就按什么写回。想强制某个文件用 LF 或 CRLF，去那个标签的「文件设置」；本来没有换行符的文档（新建文件最常见）用设置 → 常规 里选的。状态栏显示的就是保存会写入的换行符。不单独提供 CR：Monaco 的模型只会用 LF 或 CRLF 拼接行
草稿 编辑后约 500ms 防抖落盘；切标签、关标签、窗口失焦时立即冲刷
自动保存 默认关闭。打开后，当前磁盘上已存在、又有未保存改动的文件，在连续 N 秒没有再被编辑时静默写回；你再打字，这个文件的倒计时会重来，所以保存落在一次停顿之后而不是句子中间。没在看的标签既不会起新的倒计时，也不会作废正在跑的，它未保存的文本由草稿兜着。未命名标签、锁定的文件、图片，以及磁盘检查正在询问的文件都不动。它的写入默认不记版本，要在「设置 → 版本」里另外打开
恢复 打开文件时把磁盘内容与草稿比对，不一致就直接把草稿装回去，标签保持未保存状态；设置里可以改成每个文件弹「恢复草稿 / 丢弃」询问
侧边栏 资源管理器目录树（子目录懒加载 + 刷新按钮，文件夹在前、名字按自然序，2.txt 在 10.txt 前）、最近打开的历史列表，以及版本视图和源码管理视图。拖动分隔条可调宽（180–640 px，双击复位），宽度会持久化。树的文字大小可在设置里调，11–20 px
Markdown 预览 .md 标签在源码右侧渲染：GitHub 风格语法、目录、Monaco 上色的代码块、mermaid / plantuml / graphviz 围栏画成 SVG，文档旁的图片走 asset 协议加载。文档自己写的 HTML 也渲染，但受白名单约束：只放行文档中有语义的标签，行内 style 只留表现类属性，脚本、事件处理器、<style> 块和 id 一律不要
PDF 阅读 .pdf 由 pdf.js 绘制，不走文本编辑器：整篇连续滚动，按窗格宽度适应或输入 25–400 % 的缩放；纸张可选白纸、米黄、护眼绿、夜间（反相）或自选颜色。文档自带书签从角落按钮展开成一列，左右侧在「设置 → 预览」里选，可单支折叠、也可一键展开或收起整棵树，点标题跳到对应页。自动滚动按设定速度推进，滚轮或双击停下。上次读到哪一页会按文件记住
图片浏览 整个目录在一个标签里按自然序查看（IMG_2 排在 IMG_10 前）：上下排列、一张张、轮播、整页网格。子文件夹默认不含，打开后最多走四层；单次列表最多 2000 张并明确提示。图片走 asset 协议显示，不受编辑器文本大小上限约束。HEIC 与 TIFF 会被列出，并标明本渲染器画不出来
批量重命名 多选若干行，或整个目录一次改完；用一条规则（{name}、{ext}、{n}）或正则加替换，逐行预览；可按名称、扩展名、修改时间或手动排序，{n} 按这个顺序编号。详见批量重命名
版本记录 默认关闭。打开后每次手动保存都记下文件当时的内容；任意两条可以并排比对（版本与版本、或任一版本与当前编辑区），可以只看变更，也可以取回编辑器。单个文件可在标签右键菜单里排除或强制纳入，详见版本记录
源码管理 资源管理器行上显示 git 字母——被 git 忽略的路径是一个变暗的 !，整行与图标一起退到背景里——文件夹显示其下改动数；侧栏第四个视图，操作分组目录背后的一组真实仓库——按可配置深度扫描子目录，也可手动添加，或直接把远程仓库克隆进该目录——支持暂存与未暂存改动、逐文件 diff、暂存 / 取消暂存 / 丢弃、提交与历史、分支、冲突解决（含三栏合并编辑器）。详见源码管理
远程同步 通过 HTTPS 或 SSH 执行 fetch / pull（快进或合并）/ push，带进度与取消按钮；远程地址可在面板里添加、编辑与移除。凭据放在 state/git.json，不进入设置也不进入配置备份
单实例 再次启动时把路径交给已运行的窗口，新增标签并聚焦
设置 右键菜单开关、编辑器字号、minimap、界面语言；即时生效并持久化。右键菜单页还会显示当前注册表实际启动的命令，指向别的构建或当前是 debug 构建时给出警告
语言 默认跟随系统（中文 Windows 用中文，其它环境用英文），也可在设置里固定为中文或英文。所有文案（含 Rust 侧返回的报错）都走同一张 key 表
版本更新 设置 → 关于 可按需检查 GitHub 上的最新版本；启动后与每六小时也会自动检查，发现新版本只提示、不自动安装。安装仍由「下载并安装」触发：下载签名安装包后交给 passive 安装器并自动重启；自动检查可在 设置 → 关于 关闭
标签分组 一个分组就是一组有名字的标签，外加资源管理器停着的目录。标题栏上的小牌在同一窗口里切换分组，标签、光标位置和目录树一起换
移动 / 复制标签 标签右键菜单可把标签归到另一个分组。改的是「哪个分组列着它」，磁盘上的文件不动
配置备份 分组、设置、最近文件与文件夹历史的时间戳快照，应用打开和关闭时自动更新，也可手动；超过保留数会删旧的，设置 → 备份 里可任选一份恢复。不含草稿与版本历史
文件对比 两个内容只读并排 diff，任一侧可以是磁盘文件或未保存的 buffer（含未命名标签）；同一个文件的未保存版本有专用入口，重跑同一次比对即刷新快照；默认只保留一个比对标签页，可在设置里改回每次新开。未改动的区段会折叠成一行（可再展开），窄窗口自动切到单栏，头部可在并排 / 单栏之间切换
加密文件 口令派生密钥、AES-256-GCM 的自描述容器；加密另存为、新建加密文件、改口令、移除加密；空闲自动锁定；可选记住口令到 Windows 凭据管理器；草稿同钥加密
窗口 大小、位置、是否最大化都在下次启动时还原。上次所在的显示器不在了，窗口会被拉回还在用的屏幕上，并说明原因
